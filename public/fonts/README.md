# Self-hosted web fonts

Inter (400/500/600) and Space Grotesk (500/700), latin subset, WOFF2 — served
from this origin so no visitor request ever goes to Google Fonts (GDPR /
ePrivacy: no third-party IP disclosure). Both are licensed under the SIL Open
Font License 1.1 (see LICENSE-*.txt). Sourced from the @fontsource npm packages.
The @font-face rules live at the top of css/style.css.
